「RSIが30を割ったら買い、70を超えたら売り」という逆張りルールは、テクニカル分析の入門書やブログで必ず紹介される戦略の一つです。仕組みが単純で実装しやすい一方、「本当にこれだけで優位性があるのか」という疑問もよく聞かれます。この記事では、RSI逆張り戦略の仕組みと、Pythonで検証する際の基本的な手順、判断を誤りやすい落とし穴を整理します。

## RSI逆張り戦略とは何か

RSI(Relative Strength Index)は、一定期間の値上がり幅と値下がり幅の比率から「買われすぎ・売られすぎ」を0〜100の数値で表すオシケーター系の指標です。RSIそのものの計算方法は[テクニカル指標をPythonで計算する方法](/blog/python-technical-indicators/)で解説しているので、まだの方はそちらを先に確認しておくと理解しやすくなります。

逆張り戦略の考え方はシンプルです。

- RSIが30以下 → 「売られすぎ」とみなし、反発を期待して買う
- RSIが70以上 → 「買われすぎ」とみなし、反落を期待して売る

値動きが行き過ぎたら平均的な水準に戻る、という「平均への回帰(mean reversion)」の発想に基づいています。相場が一定のレンジ内で上下動している間は、この考え方は直感的にも理解しやすいものです。

## Pythonで検証の骨格を作る

実際に機能するかどうかを確かめるには、思い込みではなくコードで検証する姿勢が欠かせません。ccxtでOHLCVを取得する方法は[Python+ccxt入門](/blog/ccxt-python-tutorial/)を参照してください。

```python
import pandas as pd

def calc_rsi(close: pd.Series, period: int = 14) -> pd.Series:
    delta = close.diff()
    gain = delta.clip(lower=0).rolling(period).mean()
    loss = (-delta.clip(upper=0)).rolling(period).mean()
    rs = gain / loss
    return 100 - (100 / (1 + rs))

df['rsi'] = calc_rsi(df['close'], period=14)

# 売られすぎで買い、買われすぎで売り(簡易な逆張りシグナル)
df['position'] = 0
df.loc[df['rsi'] < 30, 'position'] = 1
df.loc[df['rsi'] > 70, 'position'] = -1
df['position'] = df['position'].replace(0, pd.NA).ffill().fillna(0)

df['returns'] = df['close'].pct_change()
df['strategy_returns'] = df['position'].shift(1) * df['returns']
```

[移動平均クロス戦略の記事](/blog/ma-cross-strategy-backtest/)と同様に、シグナルが確定した次の足からポジションを持つよう `shift(1)` を入れている点がポイントです。ここをずらし忘れると、実際には取れない未来の値動きを前提にした検証になってしまいます。

## なぜ「効きそうに見える」のか

RSI逆張りをレンジ相場のチャートに重ねて見ると、30や70に近づいたところで価格が反転している場面が目につきやすく、「効いている」という印象を持ちやすい指標です。これは人間の目が「当たった場面」を強く記憶しやすいという認知的な傾向も影響しています。

しかし実際に通期でバックテストすると、結果はパラメータ(しきい値30/70、RSIの期間14など)や検証期間、対象銘柄によって大きく振れることが少なくありません。特に強いトレンドが続く相場では、「売られすぎ」のまま一段と下げ続ける、いわゆる逆張りの刃に沿って損失が拡大するケースが典型的な失敗パターンです。

## 検証でよくある落とし穴

RSI逆張りの検証でとくに注意したいポイントを整理します。

- **しきい値の調整しすぎ**: 30/70を25/75や20/80に変えて良い成績が出る組み合わせを探す行為は、[過剰最適化(カーブフィッティング)の記事](/blog/curve-fitting-signs/)で触れた「ノイズへの合わせ込み」に陥りやすい典型例です
- **相場レジームを無視した単一期間での検証**: トレンド相場とレンジ相場では成績の傾向がまったく異なるため、ある1期間だけの検証で結論を出すのは危険です。レンジ相場・トレンド相場それぞれの区間に分けて確認する、[ウォークフォワード検証](/blog/walkforward-backtest/)のように学習期間と検証期間を分離して確認するなどの工夫が必要です
- **手数料・スリッページを含めない検証**: RSI逆張りはエントリー・エグジットの頻度が高くなりやすく、[取引コストが成績に与える影響の記事](/blog/trading-cost-impact-formula/)で解説したとおり、コストを含めると見かけの優位性が消えることがよくあります
- **勝率だけで判断する**: 逆張り戦略は「小さく当たるが、トレンドに逆らったときに大きく外れる」性質を持ちやすく、勝率が高く見えても損益の合計がマイナスになることがあります。この点は[成績指標の読み方の記事](/blog/trading-metrics-guide/)で詳しく取り上げています

## レンジ・トレンドを判定するフィルターを加える発想

RSI逆張りが機能しやすいのはレンジ相場であるという前提に立つなら、「今がレンジ相場かどうか」を判定するフィルターを組み合わせる発想が自然です。例えば長期の移動平均の傾きが小さい区間だけ逆張りシグナルを有効にする、ADXのような指標でトレンドの強さを測って高いときはシグナルを無効化する、といった工夫が考えられます。フィルターを加えるとパラメータ数が増えるため、[過剰最適化の兆候](/blog/curve-fitting-signs/)で挙げたチェック項目(パラメータ数とデータ量のバランス、感度分析など)を併せて確認することが大切です。

## まとめ

- RSI逆張りは「売られすぎ・買われすぎ」からの平均回帰を狙う、シンプルで直感的な戦略
- チャートを目で見ると効いているように感じやすいが、通期のバックテストでは期間・パラメータ・銘柄によって成績が大きく振れる
- しきい値の調整しすぎ、単一期間での検証、コストを含めない検証、勝率だけでの判断は典型的な落とし穴
- 強いトレンド相場では逆張りが不利に働きやすく、レジームを判定するフィルターとの組み合わせが検討材料になる
- 「効きそうに見える」という印象と、コスト込み・複数期間での検証結果を分けて考えることが欠かせない

RSI逆張りに限らず、テクニカル指標ベースの戦略は「仕組みが直感的に理解できること」と「実際に優位性があること」は別の問題です。採用する前に、必ず自分の手でコードを書いて検証する習慣をつけておくとよいでしょう。
