自動売買ボットの取引所を調べていると、「現物」のほかに「無期限先物(Perpetual Futures)」「仮想通貨FX」という選択肢が出てきます。名前は知っていても、現物取引と何が根本的に違うのか、ボットで扱う場合に何に注意すべきかは意外と整理されていません。この記事では、無期限先物の仕組みを現物取引と比較しながら一般論として解説します。

## 現物取引と無期限先物の根本的な違い

現物取引は、実際にBTCなどのコインそのものを売買し、保有する取引です。買った分だけ資産として持ち、上がれば含み益、下がれば含み損になります。

一方、無期限先物は「価格に連動する契約」を売買する取引です。ここに大きな違いが2つあります。

- **ショート(空売り)ができる**: 現物は基本的に「買ってから売る」しかできませんが、無期限先物は「売ってから買い戻す」ことで下落局面でも利益を狙う建て方ができます
- **レバレッジをかけられる**: 証拠金の何倍もの金額の取引を行えるため、少ない資金で大きなポジションを持てます(その分、損失も拡大します)

なお「先物」という名前ですが、一般的な先物取引(株価指数先物など)と違って**満期(期限)がありません**。その代わり、後述する「ファンディングレート」という仕組みで、契約価格が現物価格から大きく乖離しないよう調整されています。

## レバレッジの仕組みとロスカット(清算)

レバレッジは「証拠金に対して何倍の取引ができるか」を表す倍率です。例えば10倍のレバレッジであれば、10万円の証拠金で100万円分のポジションを持てます。

ここで重要なのが**清算価格(ロスカットライン)**の存在です。含み損が証拠金を食いつぶす水準に達すると、ポジションは強制的に決済されます。レバレッジが高いほど、価格のわずかな逆行でも清算価格に到達しやすくなる、という点は必ず理解しておく必要があります。

清算のリスクはボットの資金管理設計にも直結します。ポジションサイズの決め方やサーキットブレーカーの考え方は[資金管理・リスク管理の記事](/blog/bot-risk-management/)で詳しく解説しているので、レバレッジ取引を検討している場合はあわせて確認しておくとよいでしょう。

## ファンディングレート(資金調達手数料)とは

無期限先物には満期がない代わりに、**ファンディングレート**という仕組みで契約価格を現物価格に近づけています。

一般的な考え方は次の通りです。

- 契約価格が現物価格より高い(ロング優勢) → ロング保有者がショート保有者に手数料を支払う
- 契約価格が現物価格より低い(ショート優勢) → ショート保有者がロング保有者に手数料を支払う

支払いは多くの取引所で数時間おきに発生し、ポジションを保有している間ずっと発生し続けます。短期売買では影響が小さくても、ポジションを長期間保有するボットではファンディングレートの累積コストが無視できなくなることがあります。成績を評価する際は、こうした見えにくいコストも含めて判断することが大切です。この点は[成績指標の読み方の記事](/blog/trading-metrics-guide/)で触れている「数字だけを見て判断すると陥る罠」にも通じる話です。

※ファンディングレートの計算方法や支払い頻度は取引所によって異なり、変更されることもあるため、必ず利用する取引所の公式ドキュメントで最新情報を確認してください。

## Pythonのccxtで現物と無期限先物を扱う

ccxtでは、同じ取引所オブジェクトでも現物か無期限先物かで指定方法が変わります。ccxtの基本的な使い方は[ccxt入門の記事](/blog/ccxt-python-tutorial/)、メソッド一覧は[ccxtの使い方まとめ](/blog/ccxt-cheatsheet/)を参照してください。

```python
import ccxt

exchange = ccxt.mexc({
    'apiKey': 'YOUR_API_KEY',
    'secret': 'YOUR_SECRET',
})

# 現物のティッカーを取得
spot_ticker = exchange.fetch_ticker('BTC/USDT')
print('現物:', spot_ticker['last'])

# 無期限先物を扱う場合はdefaultTypeを切り替える
exchange.options['defaultType'] = 'swap'
futures_ticker = exchange.fetch_ticker('BTC/USDT:USDT')
print('無期限先物:', futures_ticker['last'])

# ファンディングレートの取得(対応取引所のみ)
funding = exchange.fetch_funding_rate('BTC/USDT:USDT')
print('ファンディングレート:', funding['fundingRate'])
```

無期限先物のシンボル表記(`BTC/USDT:USDT`のような形式)や、レバレッジ・証拠金モードの設定方法は取引所ごとに異なります。実際にコードを書く前に、必ず利用する取引所のccxt向けドキュメントで対応状況を確認してください。

## ボットで無期限先物を扱う前に確認したいこと

現物向けに作ったボットのロジックをそのまま無期限先物に流用すると、想定外の挙動につながることがあります。設計段階で確認しておきたい点を挙げます。

- **証拠金モード**: ポジションごとに証拠金を分けるアイソレートモードか、口座全体の証拠金を共有するクロスモードか。清算の範囲が大きく変わります
- **デフォルトのレバレッジ設定**: 取引所によっては口座やシンボルごとにデフォルトのレバレッジが設定されており、意図しない倍率で注文が通ることがあります。発注前に必ず現在の設定を確認するロジックを入れておくと安全です
- **清算価格の把握**: ポジションを持った時点で清算価格がどこにあるかを把握し、ロジックの中で監視することが望ましいです
- **ショートポジションのロジック**: 現物にはない「ショートから入る」戦略を組む場合、ロング前提で書いたコードの符号や条件分岐を見直す必要があります

無期限先物はレバレッジによって利益も損失も現物より大きく増幅されます。どの程度のレバレッジ・ポジションサイズが妥当かに絶対的な正解はなく、資金管理の考え方とセットで検討すべき領域です。判断は自己責任で行い、取引所や商品の仕組みについては必ず公式情報を確認してください。

## まとめ

- 無期限先物は「契約の売買」であり、現物と違ってショートやレバレッジが使える
- 満期はないが、代わりにファンディングレートで現物価格との乖離を調整する仕組みがある
- レバレッジをかけるほど清算価格に到達しやすくなり、リスクが増幅する
- ccxtでは`defaultType`の切り替えやシンボル表記の違いに注意が必要
- 証拠金モード・デフォルトレバレッジ・清算価格の把握など、現物にはない確認項目がボット設計に加わる

無期限先物は現物にはない自由度がある一方、レバレッジという増幅装置が加わることで設計・運用の難易度も上がります。まずは現物での運用に慣れてから、資金管理の考え方を固めた上で検討するのが無難です。あわせて[自動売買ボットは儲かるのかの記事](/blog/is-bot-profitable/)も参考にしてください。
