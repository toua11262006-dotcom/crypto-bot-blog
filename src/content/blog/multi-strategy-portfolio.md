グリッド、移動平均クロス、DCA(積立)…。ボットの戦略を一つ検証して満足すると、次に出てくる疑問が「複数の戦略を同時に動かしたほうがいいのか」です。1つの戦略だけに資金を集中させると、その戦略が機能しない相場が続いた時の影響をまるごと受けてしまいます。この記事では、複数戦略を組み合わせる「ポートフォリオ」的な考え方を、一般的な理論として整理します。

## なぜ複数戦略を組み合わせたくなるのか

単一の戦略は、ある特定の相場環境を前提に作られていることがほとんどです。例えば次のような特性があります。

- **トレンドフォロー系**(移動平均クロスなど): トレンドが続く相場で機能しやすいが、レンジ相場では細かい逆行で損失が積み重なりやすい
- **グリッド・逆張り系**: レンジ相場で機能しやすいが、一方向に強く動くトレンド相場では不利な方向に在庫を積みやすい
- **積立(DCA)系**: 相場環境に関わらず機械的に買い増すため、短期的な上下に強く依存しない

[移動平均クロス戦略の検証](/blog/ma-cross-strategy-backtest/)や[グリッドボットのレンジ設定](/blog/grid-bot-range-setting/)で見たように、それぞれの戦略には得意・不得意な相場環境があります。1つの戦略だけで運用すると、その戦略が不得意な環境が続く期間は、資金全体が苦しい状態に置かれ続けることになります。

## ポートフォリオ理論の基本的な考え方

複数の資産や戦略を組み合わせることでリスクを下げられる、という考え方は、伝統的な金融の「ポートフォリオ理論」で古くから整理されています。要点をシンプルに言うと次の通りです。

- 2つの戦略の成績が**完全に同じ方向に動く(相関が高い)**なら、組み合わせても分散効果はほとんどない
- 2つの戦略の成績が**異なる方向に動きやすい(相関が低い、または負の相関)**なら、片方が不調な時にもう片方が補う効果が期待できる

ここで重要なのは、「それぞれの戦略の期待値が高いこと」ではなく「戦略同士の相関が低いこと」に分散の価値がある、という点です。優秀な戦略を2つ集めても、両方が同じ相場環境でしか機能しないなら、分散の効果は限定的です。

## 戦略間の相関を確認する

実際に相関を確認するには、各戦略をバックテストして得られた期間ごとの損益(リターン)の系列を並べ、相関係数を計算します。

```python
import pandas as pd

# 各戦略の日次リターン(バックテスト結果から作成した例)
returns = pd.DataFrame({
    'trend_follow': trend_follow_daily_returns,
    'grid': grid_daily_returns,
    'dca': dca_daily_returns,
})

correlation_matrix = returns.corr()
print(correlation_matrix)
```

相関係数は-1〜1の値を取り、1に近いほど「同じ方向に動く」、0に近いほど「無関係」、-1に近いほど「逆方向に動く」ことを示します。トレンドフォロー系とレンジ系(グリッド)は理論上、得意な相場環境が異なるため相関が低くなりやすいと言われますが、これは相場環境によって変わるため、実際の相関は自分のバックテストデータで確認する必要があります。

なお、バックテスト結果だけを見て「この組み合わせは相関が低いから最適だ」と決め打ちするのは危険です。特定の期間だけを切り出して都合よく見える組み合わせを選んでしまう罠については、[カーブフィッティングの兆候](/blog/curve-fitting-signs/)で解説している内容がそのまま当てはまります。

## 資金配分の考え方

相関を確認したら、次は各戦略にどれだけ資金を配分するかを決める必要があります。代表的な考え方を2つ紹介します。

### 等金額配分(イコールウェイト)

もっとも単純な方法で、戦略数で資金を均等に割るだけです。実装も検証もしやすく、まず手を出しやすい方法です。

```python
strategies = ['trend_follow', 'grid', 'dca']
capital_per_strategy = total_capital / len(strategies)
```

### リスクベースの配分(リスクパリティの考え方)

戦略ごとにボラティリティ(成績のブレの大きさ)が異なる場合、単純に等金額で配分すると、ブレが大きい戦略が全体のリスクを支配してしまいます。そこで、各戦略のボラティリティに反比例する形で資金を配分する考え方があります。

```python
import numpy as np

volatilities = returns.std()  # 各戦略の日次リターンの標準偏差
inverse_vol = 1 / volatilities
weights = inverse_vol / inverse_vol.sum()

allocation = total_capital * weights
print(allocation)
```

この方法はボラティリティが低い戦略に多く資金を配分し、ボラティリティが高い戦略には少なく配分することで、戦略ごとのリスク寄与を均そうとする考え方です。あくまで一つの考え方であり、必ずしも等金額配分より優れているとは限らない点には注意してください。

## 運用面で見落としやすい注意点

理論上は分散効果があっても、実際の運用では次のような点に注意が必要です。

- **資金の分離**: 複数戦略を同じ口座の残高で動かすと、どの戦略がどれだけの資金を使っているかが曖昧になりやすく、[ポジションサイズの計算式](/blog/position-sizing-formula/)の前提が崩れます。[取引所のサブアカウント機能](/blog/exchange-sub-account-separation/)で資金そのものを分けておくと、計算も損益の集計もシンプルになります
- **同一銘柄での注文の衝突**: 複数戦略が同じ銘柄を同時に扱うと、片方が買い注文を出している最中にもう片方が売り注文を出すなど、意図しない相殺が起きることがあります。戦略ごとに扱う銘柄を分けるか、注文を一元管理する仕組みが必要です
- **相関は相場急変時に変化しうる**: 平常時は相関が低く見えても、市場全体が大きく崩れる局面では、多くの戦略が同時に損失を出す方向に相関が強まることが一般的に指摘されています。分散していても「資金が一発で大きく減るリスク」がゼロになるわけではない、という前提は持っておくべきです
- **管理コストの増加**: 戦略が増えるほど監視・ログ・障害対応の手間も増えます。[資金管理の基本](/blog/bot-risk-management/)で触れた「退場しないこと」を最優先に、無理に戦略数を増やしすぎないことも大切です

## 成績の評価は戦略単位・全体単位の両方で見る

複数戦略を運用し始めたら、全体の損益だけでなく、戦略ごとの損益も個別に追えるようにしておくことが重要です。[ボットの損益計算](/blog/bot-pnl-calculation/)を戦略単位で分けて記録しておけば、「どの戦略が全体の成績を支えているか」「どの戦略が想定通りに機能していないか」を後から検証できます。

全体の成績を見る際も、勝率や総リターンだけで判断すると実態を見誤りやすい点は単一戦略の場合と同じです。[ボットの成績指標の読み方](/blog/trading-metrics-guide/)で整理したように、最大ドローダウンやプロフィットファクターなど複数の指標を組み合わせて評価する姿勢は、ポートフォリオ全体を見るときにも変わらず重要です。

## まとめ

- 単一戦略への資金集中は、その戦略が不得意な相場環境が続くと資金全体が苦しくなるリスクがある
- 分散の価値は「それぞれの戦略が優秀かどうか」ではなく「戦略同士の相関が低いかどうか」にある
- 相関はバックテストのリターン系列から相関係数を計算して確認できるが、特定期間への過剰最適化には注意する
- 資金配分には等金額配分とリスクベース配分(ボラティリティに反比例)という代表的な2つの考え方がある
- 資金の分離・銘柄の衝突・相場急変時の相関変化・管理コストの増加は、理論だけでは見えてこない運用上の注意点
- 評価は全体の損益だけでなく、戦略単位の損益・指標も合わせて追うことが望ましい

複数戦略の組み合わせは、うまく機能すれば単一戦略よりも安定した運用につながる可能性がある一方、設計・運用の複雑さも増します。まずは1つの戦略をきちんと検証・運用できる状態を作り、資金管理の土台を固めたうえで、段階的に戦略数を増やしていくのが無難な進め方です。
