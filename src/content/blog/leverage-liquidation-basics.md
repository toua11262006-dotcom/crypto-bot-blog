無期限先物(仮想通貨FX)の取引所を調べていると、「レバレッジ10倍」「証拠金維持率」「強制ロスカット」といった言葉が次々に出てきます。なんとなく「借金してでかく張る仕組み」という理解で止まっている人も多いのではないでしょうか。この記事では、レバレッジがどういう仕組みで成り立っているのか、そして強制ロスカット(清算)がどのタイミングで発生するのかを、一般論として整理します。

## レバレッジとは何か

レバレッジは「証拠金に対して何倍の金額のポジションを持てるか」を表す倍率です。例えば証拠金10万円でレバレッジ10倍をかけると、100万円分のポジションを持てます。

ここで重要なのは、**レバレッジは利益も損失も同じ倍率で拡大する**という点です。価格が1%動けば、証拠金に対する損益は10倍のレバレッジなら10%動きます。レバレッジ自体は「資金効率を上げる仕組み」であり、「勝率を上げる仕組み」ではありません。無期限先物の基本的な仕組み(現物との違いやファンディングレート)は[無期限先物の基礎知識の記事](/blog/perpetual-futures-basics/)で解説しているので、あわせて確認しておくとよいでしょう。

## 証拠金(マージン)には2種類の意味がある

レバレッジ取引を理解するうえで混乱しやすいのが、「証拠金」という言葉が2つの意味で使われる点です。

- **初期証拠金(Initial Margin)**: ポジションを新規に開くために必要な金額。レバレッジ倍率から逆算される
- **維持証拠金(Maintenance Margin)**: ポジションを維持するために最低限必要な金額。初期証拠金より小さいのが一般的

そして、現在の口座残高(または証拠金として割り当てた金額)が維持証拠金をどれだけ上回っているかを示す指標が**証拠金維持率**です。

```
証拠金維持率 = 口座残高(または割当証拠金) ÷ 維持証拠金 × 100
```

この維持率が一定水準を下回ると、取引所によって強制的にポジションが決済されます。これが「強制ロスカット」「清算(Liquidation)」と呼ばれる仕組みです。

## 強制ロスカット(清算)はどう決まるか

清算価格のおおよその考え方は、次の要素で決まります。

- エントリー価格
- レバレッジ倍率(証拠金に対するポジションの大きさ)
- 維持証拠金率(取引所・銘柄ごとに決められている最低限の比率)

考え方としては、含み損が証拠金のうち「維持証拠金率を上回る部分」を食いつぶした時点で清算が発動します。レバレッジが高いほど、同じ資金で持てるポジションが大きくなる分、証拠金に対する価格変動の影響も大きくなり、清算価格までの距離が近くなります。

分離マージン(Isolated Margin)でロングポジションを持つ場合の、おおまかな清算価格の考え方をPythonで書くと次のようになります。あくまで仕組みを理解するための簡略化した計算式であり、実際の清算価格は取引所ごとの計算方法(手数料や未実現損益の扱いなど)によって変わります。

```python
def estimate_liquidation_price(entry_price: float, leverage: float, maintenance_margin_rate: float) -> float:
    """分離マージン・ロングポジションの概算清算価格を計算する(簡略化モデル)"""
    # レバレッジが高い(=証拠金に対するポジションが大きい)ほど、
    # 清算価格はエントリー価格に近づく
    price_drop_ratio = (1 / leverage) - maintenance_margin_rate
    return entry_price * (1 - price_drop_ratio)


# 例: エントリー価格 5,000,000円、レバレッジ10倍、維持証拠金率0.5%
print(estimate_liquidation_price(5_000_000, 10, 0.005))
```

レバレッジを10倍から20倍に上げると、同じ資金でもこの `price_drop_ratio` が小さくなり、清算価格がエントリー価格にぐっと近づくことが分かります。レバレッジを上げるほど「ちょっとした逆行」でも清算に達しやすくなる、というのはこの計算式からも読み取れます。

※清算価格の正確な計算方法(手数料・未実現損益・保険基金の扱いなど)は取引所ごとに異なり、変更されることもあります。実際の取引に使う前には、必ず利用する取引所の公式ドキュメントで最新の計算方法を確認してください。

## クロスマージンと分離マージンの違い

多くの取引所では、証拠金の割り当て方として2つの方式が用意されています。

| 方式 | 証拠金の割り当て | 特徴 |
| --- | --- | --- |
| 分離マージン(Isolated) | そのポジション専用に証拠金を固定 | 損失がそのポジションの証拠金に限定される。清算価格を把握しやすい |
| クロスマージン(Cross) | 口座全体の残高を証拠金として共有 | 他のポジションの余力で持ちこたえやすいが、損失が口座全体に及ぶ可能性がある |

ボットで複数のポジションを同時に扱う場合、クロスマージンだと「あるポジションの含み損が、別のポジションの証拠金余力まで食いつぶす」状態になり得ます。どちらの方式を採用しているかは取引所・口座設定によって異なるため、ボットを本番で動かす前に必ず確認しておくべき項目です。

## レバレッジがボット設計に与える影響

レバレッジを使う場合、ボットの設計で意識すべき点は大きく2つあります。

1. **ポジションサイズの計算にレバレッジを織り込む**: 「何倍のレバレッジをかけるか」ではなく「清算価格までの距離が、自分が許容できる損失額に対して十分に余裕があるか」から逆算するのが安全な考え方です。具体的な計算式は[ポジションサイズの計算式の記事](/blog/position-sizing-formula/)で詳しく解説しています
2. **資金管理のルールと組み合わせる**: 連敗時に自動停止する仕組みなど、レバレッジで拡大した損失を一定以上広げない仕組みが必要です。考え方は[資金管理・リスク管理の記事](/blog/bot-risk-management/)にまとめています

また、清算は「取引所側の判断」で強制的に行われる決済であり、自分のボットの損切りロジックより先に発動してしまうこともあります。ロジック上は「このラインで損切りする」と決めていても、急激な価格変動やスプレッドの広がりによって、想定より早く清算価格に到達するケースがある点は覚えておく必要があります。取引所の障害時にどう備えるかは[取引所の障害とフェイルセーフの記事](/blog/exchange-outage-failsafe/)も参考になります。

## まとめ

- レバレッジは証拠金に対するポジションの倍率で、利益だけでなく損失も同じ倍率で拡大する
- 証拠金維持率が一定水準を下回ると、取引所によって強制的にポジションが決済される(強制ロスカット・清算)
- レバレッジが高いほど、清算価格がエントリー価格に近づき、少しの逆行でも清算に達しやすくなる
- クロスマージンか分離マージンかで、損失の広がり方が変わる
- 清算価格やマージン方式の詳細は取引所ごとに異なり、変更されることもあるため、必ず公式ドキュメントで最新情報を確認する
- ボットの設計では、レバレッジを含めたポジションサイズの計算と、資金管理ルールを組み合わせて検討する
